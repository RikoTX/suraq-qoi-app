# Сұрақ қой — Обыграй ИИ

Тренажёр функциональной грамотности (чтение) для учеников 7–9 классов, который работает при слабом интернете. Ученик читает короткий текст и сам задаёт к нему вопросы, а ИИ оценивает, насколько глубоко он понял текст.

Проект для [Órleu Hack 2026](https://hackathon.kz/hackathon?slug=orleu-hack-2026), кейс 3 «Образование: читать и понимать».

## Проблема

По PISA-2025 базового уровня по чтению достигают только 36% казахстанских 15-летних. В сельских школах к этому добавляются слабый интернет и нехватка материалов. ИИ-чаты дают готовые ответы, и ученик не учится думать.

## Решение

- **Ученик задаёт вопросы, а не отвечает на них.** Вопрос получает уровень: найти → связать → вывести → оценить (по навыкам чтения PISA). Чем глубже вопрос, тем больше очков.
- **Работает при слабом интернете.** Приложение открывается из кеша, тексты хранятся на устройстве. ИИ оценивает вопрос сразу; если ответ не пришёл за 8 с, ученик видит предварительную оценку, а точная придёт позже. Ни один ответ не теряется.
- **Казахский и русский.** Тексты о жизни в Казахстане: расписания, объявления, новости, посты.
- **Учитель ведёт свой класс.** Тексты пишет сам, генерирует ИИ по теме урока или берёт из общей библиотеки — и публикует. Видит карту навыков класса, вопросы каждого ученика, может поправить оценку ИИ.
- **Админ наблюдает за проектом.** Сколько учителей, учеников, классов и текстов, кто зарегистрирован.

## Стек

| Часть | Технологии |
|---|---|
| Фронтенд | React 19 · Vite · TypeScript · PWA (Workbox, Dexie) · Tailwind · i18next |
| Бэкенд | ASP.NET Core (.NET 9) · EF Core · PostgreSQL · JWT · OpenAPI/Scalar · xUnit |
| ИИ | Open-source модели через Groq (OpenAI-совместимый API): `openai/gpt-oss-120b` — генерация текстов, `openai/gpt-oss-20b` — оценка вопросов. Сервер и модели меняются в настройках (можно переключить на OpenAI) |
| Деплой | Собственный сервер · Docker Compose · Caddy (HTTPS) |
